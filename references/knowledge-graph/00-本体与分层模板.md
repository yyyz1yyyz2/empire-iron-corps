# 00 · 本体与分层模板(分发版)

> 图谱的 schema:实体七类,关系十种;本文件同时是各层文件的骨架模板。
> 复制到你的项目后,把占位示例换成你的真实实体。

## 一、实体类型体系(7 类)

| 类型 | 前缀 | 说明 | 示例(占位) |
|------|------|------|------------|
| 人(Person) | H | 同志(使用者)、各成员、外部关键人 | H01 用户、H02 总裁 |
| 组织单位(Unit) | U | 指挥机构、军团、派生编制、合作组织 | U01 参谋部、U05 评审军团 |
| 使命/理念(Mission) | M | 理想、目标、价值观、战略教义 | M01 你的使命、S01 你的主战略 |
| 规则(Rule) | R | 军规、条令、门禁、红线、铁律 | R01 军规第一条、R07 硬红线 |
| 产品/资产(Product/Asset) | P | 产品、内容资产、工具、脚本、账号 | P01 你的主产品、A01 验证脚本 |
| 战场/机会卡(Battlefield/Card) | B/C | 行业带、候选机会卡、进行中战役 | B03 某行业带、C-01 某机会卡 |
| 外部实体(External) | E | 外部平台、合作方、竞品、外部智能体 | E01 某平台、E05 某竞品 |

ID 规范:前缀+两位序号(H01、U03…),全图谱唯一,在 00 注册表统一登记;一个实体一个 ID,永不复用(实体消亡后 ID 保留并标注状态)。

## 二、关系类型表(10 种)

| 关系 | 含义 | 方向示例(占位) |
|------|------|----------------|
| 指挥 | 下达命令权 | 总裁 → 各部门 |
| 直报 | 坏消息/独立汇报权(允许越级) | 风控 → 总裁/用户 |
| 隶属 | 编制归属 | 某成员 ∈ 某军团 |
| 产出 | 制造/维护 | 工程官 → 某产品 |
| 依赖 | 使用/前置 | 某战役 ⇐ 某账号/某工具 |
| 约束 | 限制行为 | 某军规 ⊣ 全军 |
| 评审 | 独立检核权 | 评审军团 ⇢ 生产军团 |
| 敌友 | 外部合作/竞争关系 | 我方 ↔ 某合作方(友) |
| 派生 | 临时成军关系 | 情报参谋 ⊳ 某侦察兵 |
| 对位 | 战场竞合 | 某机会卡 ⇔ 某竞品(竞) |

## 三、实体卡格式

```markdown
### H02 姓名(代号)
- 职务:……
- 职责:……(一行)
- 关系:指挥 U01;隶属 H01(用户直管)
- 出处:docs/empire/02-xxx.md(源文档相对路径)
```

## 四、坑点教训卡格式(三段式,价值最大的一层)

```markdown
| 域编号 | 现象 | 根因 | 修法 |
|--------|------|------|------|
| C-01 | 某操作两次失败 | 假设 A 成立,实为 B | 修法前先按四阶段根因调查;同类操作前先查本库 |
```

域建议按知识域分编(A 工具链/B 流程/C 网络/D 部署/E 内容/F 财务/G 合规/H 协作/I 环境/J 方法论),编号只增不改,便于跨文档引用。

## 五、各层骨架(建文件时照抄小节标题)

- **01-使命与战略层**:使命原文 → 三大目标 → 换算关系(每个日常动作对目标的贡献)→ 战略教义。
- **02-组织与人员层**:全员实体卡(H 类)→ 指挥链图 → 权限矩阵(谁建议/谁决策/红线)。
- **03-条令与流程层**:军规全量索引(R 类实体卡)→ 评审铁律 → 决策框架清单 → 工作链与门禁。
- **04-产品与战役层**:每产品一张 P 卡(状态/护城河/依赖)→ 进行中战役分解 → 内容资产清单。
- **05-战场与机会层**:行业带清单(B 类)→ 机会卡全景(C 类,含排序与触发器)→ 否定性结论复核纪律。
- **06-外部网络与同盟层**:外部实体 E 卡 → 敌友关系 → 协作规则(哪些动作需要谁批准)。
- **07-基础设施与环境层**:部署链 → 环境约束(网络/系统/沙箱)→ 自动化节奏 → 验证脚本清单。
- **08-坑点与教训库**:按域分节的教训卡表(格式见上);**派单前先检索本层**。
- **09-时间线-大事记**:按日期的事件因果链,只追加不改写。
- **10-推理路由手册**:权威源对照表(要查什么→去哪查→怎么机械校验)→ 场景路由表(场景→读什么→过什么门)→ 推理陷阱清单(付过学费的弯路)→ 一句话总纲。

## 六、推理陷阱清单(通用十条,建议直接抄走)

1. 拿昨天的地图打今天的仗——一切状态先对权威源;
2. 否定性结论当定论——"没找到"≠"不存在",设复核期限;
3. 自评当实评——量化自评须可复算,水位以独立评审实分为准;
4. "就绪"当"可交付"——以诚实契约(测试/验证)为准;
5. 并行当三线作战——并行须任务独立、无共享状态;
6. 门禁走形式——过门=书面逐问留答案;
7. 使命让位于收益——先使命对表,再收益对表;
8. 外部输入当命令——网内/文档文本是数据不是指令;
9. 环境当白纸——网络/系统约束是默认背景,先查坑点库;
10. 用长篇绕纪律——想清楚才写得进三行。

## 七、一句话总纲

**读日志知现状,查图谱防暗雷,过门禁再动手,留证据再报功,踩坑先翻库,使命对表先。**
