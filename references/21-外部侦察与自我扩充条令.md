# 21 外部侦察与自我扩充条令 —— 向外学习,化为己用

> 远征军永续令的外向延伸(2026-10-07 立,分发版首载):军队不仅要向内增强(修人设、固脚本、完善宪章),还要**不断向外部世界侦察优秀实践,评估、试用、吸收、化为团队战力**。
> 本条令从属于 `00-组织总纲.md` 与 `01-铁军条令.md`;与 `10-远征军-侦察兵条令.md` 同构(侦察不算开火,立项归裁决),冲突时以铁军条令为准。

## 一、定位:为什么向外学习是一等军务

- **闭门造车是最大的浪费**:全球开源社区每天产出经过千锤百炼的工作流、提示词工程、智能体框架、技能与脚本——其中大量可直接化为己用;自己重新发明,既是浪费,也永远追不上。
- **吸收是双向的**:军械级吸收(工具直接装)解决"手快";教义级吸收(方法论改写进宪章)解决"脑强"。两手都要。
- **纪律先于速度**:外面什么都能看,不是什么都该拿——许可证、质量、红线、维护成本,四道门一个不少(见 §四)。

## 二、侦察源(主战场:GitHub)

| 源 | 侦察什么 | 怎么找 |
|----|---------|--------|
| GitHub awesome 列表 | 各主题精选资源索引(awesome-agents/awesome-prompts/awesome-workflows 等) | 按"awesome + 主题"搜索,从列表再下钻 |
| GitHub 高星仓库 | 智能体框架、技能包、工作流引擎、提示词库、评测基准 | 搜索词 + 按 star/最近更新排序,关注趋势 |
| 技能/插件生态 | 平台技能包(如各 AI 编码器的技能市场)、MCP 服务、插件 | 官方目录 + 社区精选 |
| 技术社区/博客 | 方法论文章、复盘帖、踩坑记录 | 按问题反向搜索 |
| 竞品/同行 | 对手的更新日志、发布节奏、定价与定位变化 | 定期盯梢,变化即情报 |

**仓库质量四判据**(防"高星陷阱"):① 活跃度(近期是否仍有提交/issue 有响应);② star 趋势(近期增速,而非历史总量);③ 文档质量(README 是否可复现);④ 许可证(见 §四许可证三查)。

## 三、侦察任务书四问(缺一不发,与远征军同构)

1. **使命换算**:吸收它,对使命三目标推进什么?
2. **真实价值**:它解决什么问题,证据是什么(文档/issue/实测,而非宣传语)?
3. **承接成本**:安装/学习/维护成本多少?与现有军械是否重叠(能复用的不重造)?
4. **红线干净**:许可证是否允许?是否涉及条令第 7 条硬红线?

## 四、吸收五步(评估到入库的完整链路)

```
侦察(只读,不注册不留痕)
  → 评估(四问 + 许可证三查)
  → 试用(小规模沙箱,90 天内会真用才留)
  → 入库(军械登记 / 宪章迭代)
  → 复盘(值不值、坑在哪;退役也登记理由)
```

1. **许可证三查**(吸收任何代码/内容前):① License 类型(是否允许本项目用途);② 商用条款;③ 传染性(GPL 类是否可隔离)。查不清=不吸收。
2. **90 天真用纪律**:每一波吸收不超过 15 件;装了 90 天内没有真用过一次的,退役——**军械库是弹药库,不是收藏馆**。
3. **军械级吸收**:工具/脚本/技能直接装,登记进军械库台账(格式见 templates/军械库登记模板.md):名称/来源/许可证/用途/装期/最近真用日。
4. **教义级吸收**:方法论不能照抄——先做**对标拆解**(它做对了什么/我们能吸收什么/差异化在哪),再本土化改写进宪章或条令,注明出处与拆解记录。宪章是唯一事实源,改它走宪章迭代纪律。
5. **退役登记**:不再使用的军械与证伪的方法论,登记退役理由入库——"试过且不行"与"没试过"是两种完全不同的知识。

## 五、与知识图谱联动

- 吸收成果当天入谱:军械登记为资产实体(依赖关系挂到使用它的战线);对标拆解与退役理由入坑点教训库(三段式:现象→根因→修法)。
- 教义级吸收产生的宪章修订,过对应 verify 脚本后才算完成(结构性变化当天入谱,易变状态永不入谱)。

## 六、定期体检(全军审计)

自我扩充需要配套的防漂移机制,建议每季度一次:

1. **三验连跑**:宪章结构验证 + 知识图谱校验 + 台账校验,全绿才算体检通过;
2. **账实对拍**:抽 N 项登记在册的状态/数字,对权威源(代码仓/日志/实跑)核验——图谱与台账说谎是最大的暗雷;
3. **评审一致性抽查**:同稿双评比对,分差过大即查评审席是否漂移;
4. **军械库盘点**:清 90 天未用件,退役登记;
5. 体检报告进作战日志,发现的漂移当天修。

## 七、红线

- 侦察只读不外:不注册、不留言、不留联系渠道;一切对外动作归同志拍板。
- 宣传口径不当实证:star 数不等于质量,README 不等于实测——一切"优秀"判断必须挂证据级别。
- 不吸收:许可证不明件、无人维护件(最后提交超一年且 issue 堆积)、与硬红线冲突件。
- 吸收不等于堆砌:每装一件,问一句"它替代了什么"——只加不减的军械库必然腐化。
